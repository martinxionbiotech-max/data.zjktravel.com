## 京张高铁概况

京张高铁（含崇礼支线）全长174公里，设计时速350km/h，于2019年12月30日开通运营。北京北站/清河站至张家口站最快47分钟，至崇礼太子城站约1小时15分钟。

**关键运营参数**

| 参数 | 数据 |
|------|------|
| 线路全长 | 174 km（北京北—张家口） |
| 设计时速 | 350 km/h |
| 运营时速 | 300-350 km/h |
| 日开行对数 | 60+ 对 |
| 首班车(北京发) | 约06:00 |
| 末班车(北京发) | 约22:30 |
| 主要发车站 | 北京北站、清河站 |
| 沿途站点 | 清河—昌平—八达岭长城—东花园北—怀来—下花园北—宣化北—张家口 |
| 崇礼支线 | 下花园北分叉→太子城/崇礼 |
