张家口主要景点呈现 **"一核两带"** 分布格局：

- **一核**：崇礼-赤城冰雪温泉度假带（冬奥核心区）
- **北带**：张北-沽源-康保草原生态带（草原天路沿线）
- **南带**：涿鹿-蔚县历史文化带（三祖文化+空中草原）
